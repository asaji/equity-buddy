Twitter Authentication

RECOMMENDED

Export cookies from your browser

Most reliable method. Twitter's login flow often blocks automated sign-ins.

  1. Log into x.com in Chrome or Firefox
  2. Install Cookie-Editor extension
  3. Click Cookie-Editor → Export → Export as JSON
  4. Save to /mnt/user/appdata/equitybuddy/cookies/twitter_cookies.json
  5. Restart the worker: docker restart equitybuddy-worker
